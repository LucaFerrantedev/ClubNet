# ClubNet FrontEnd

Frontend web desarrollado en Angular

## Instalación

Para levantar el proyecto:

```bash
# Clonar el repositorio
git clone https://github.com/LucaFerrantedev/ClubNet.git

# Entrar a la carpeta del proyecto
cd clubnet

# Instalar dependencias
npm install

# Levantar el servidor de desarrollo
ng serve
